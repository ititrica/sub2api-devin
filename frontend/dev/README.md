# 本地界面预览

在 `frontend` 目录执行：

```sh
npx --yes pnpm@10 dev:mock
```

访问 <http://127.0.0.1:5179/dashboard>。启动后自动使用演示管理员登录，仪表盘、用量、密钥、用户、分组和设置使用同一组合成请求数据；切换日期、粒度、筛选条件时，图表与合计同步变化。

- 用户端导航：<http://127.0.0.1:5179/dashboard?demoRole=user>
- 管理端导航：<http://127.0.0.1:5179/admin/dashboard?demoRole=admin>
- 首页：<http://127.0.0.1:5179/home>

角色选择保存在此开发地址的浏览器存储中。测试密钥以 `sk-demo-local-only-` 开头，无法调用真实服务。新增、修改、删除演示密钥、用户、分组或设置，只修改 Vite 进程内存；重启开发服务器即可重置。

该模式只监听本机、禁用所有后端代理，并将 API 地址固定为同源 `/api/v1`。未模拟的接口返回明确的 501 响应，不会转发到真实后端。模拟模块由 Vite 配置加载，不会导入网页生产代码；普通 `dev`、构建及现有 Docker 实例不启用模拟数据。
